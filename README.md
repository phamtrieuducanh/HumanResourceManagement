Ứng dụng HRM của chúng tôi, được phát triển bằng C# và kiến trúc MVC, 
cung cấp một bộ công cụ mạnh mẽ để quản lý nhân sự hiệu quả. Các chức năng chính bao gồm quản lý thông tin nhân viên, 
hợp đồng, chấm công, tính lương, nghỉ phép, tuyển dụng, đào tạo và đánh giá hiệu suất, cùng với các báo cáo phân tích

chức năng (DFD, Use Case), mô hình dữ liệu (ERD) và mô hình động (State Diagram, Activity Diagram), đảm bảo hệ thống đáp ứng tối ưu nhu cầu doanh nghiệp.

Human Resource Management (HRM) Software – A Comprehensive Solution for Modern Businesses
Our HRM application, developed with C# and an MVC architecture, offers a powerful suite of tools for effective human resource management. 
Key functionalities include employee information management, contracts, timekeeping, payroll, leave management, recruitment, 
training, and performance evaluation, along with detailed analytical reports. The MVC model ensures modularity, scalability, 
and testability. Development was based on functional analysis models (DFD, Use Case), data models (ERD), 
and behavioral models (State Diagram, Activity Diagram), ensuring the system optimally meets business needs.
